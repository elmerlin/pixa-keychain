Chosen mark

Keeper tooth. Prism Corner gains one 2×2 tooth at (6,12)–(8,14). The original 4×4 counter, four Prism cells, silhouette bounds and clear space stay intact. It survives at 16px without hand hinting. Extension PNGs use a fixed charcoal canvas, like the parent brand favicon, to work on either browser toolbar.

The two-line lockup reuses the exact eight Pixtopia letter paths. Keychain is custom outlined geometry with the same four-unit stems, integer vertices, square dot and chamfered corners. Neither line embeds or loads a font. The mark and Pixtopia line preserve the source lockup's scale and spacing.

New glyph masters

24 new masters: trash, eye, eye-off, unlock, at, maximum, grip, gift, clock, pause, vote, keyboard, network, logout, sliders, theme, sun, moon, plug, energy, resource, savings, delegate and warning. Every master is ten by ten cells, rendered as non-overlapping 2×2 fills in the central 20×20 of a 24×24 viewBox. Other controls reuse the supplied Pixtopia glyphs; up variants bake a 180° flip into their coordinates.

97 control assets use this set. The previously missing menu/rpc/close-button.svg now resolves the existing enum entry. No enum or component changes were needed. PIXA's open window, PXS's stable bars and Pixa Power's rising steps differ in silhouette. Success is a check seal, Oops/empty is a quiet speech-bubble face, and warning is a stepped triangle.

Necessary PNG compatibility

Two existing raster filenames are hardcoded by components and detached-window CSS: placeholders/account-placeholder.png and background/detached-popup-background.png. They are replaced in place by authored pixel artwork, using the permitted exception for necessary pixel illustrations. Both keep adjacent SVG masters. The account placeholder is a 96px neutral pixel portrait with one sky accent; the detached canvas is a 256px transparent field of quiet neutral dots that works on either canvas. No component or CSS references changed, and no original raster artwork remains.

Reproduce and verify

python3 docs/design/build-graphics.py regenerates vectors, the four icon PNGs and the two necessary compatibility PNGs using resvg, reading the sibling brand repository without modifying it. python3 docs/design/build-sheets.py rebuilds the self-contained offline HTML sheets with embedded Geist fonts. The PNG contact sheet is a full-page Chrome screenshot at 1440 CSS pixels, device scale 1.

npx webpack --config webpack/chromium/webpack.prod.js
python3 docs/design/verify-graphics.py

The verifier checks the glyph grid, monochrome fills, no strokes, no embedded image/text/filter elements, brand palette and counter, all four PNG dimensions, every icon enum path, manifest-only icon edits, packaged manifest paths, and absence of deleted runtime references. No signing or transaction code is used.

Final verification: production build exited 0 with two bundle-size warnings; all 121 packaged graphics match their source bytes; 17 manifest paths and all icon enum paths resolve. Both sheets were opened in Chrome at device scale 1 and inspected at 16px, with no broken images or page errors. The graphics reviewer returned ship. Verification record.
